# 🛒 বাজার দর | BazarDor

**BazarDor (বাজার দর)** is a modern Bangla market price tracking web application that helps users quickly check the current prices of essential products in Bangladesh.

The platform provides product-wise pricing information, price changes, categories, and market-level details in a simple and user-friendly interface.

🌐 **Live Website:** https://bazardor-six.vercel.app/

---

## ✨ Features

### 1. 📊 Current Market Prices

View the latest prices of essential products such as rice, lentils, oil, vegetables, fish, meat, eggs, and spices in one place.

### 2. 📈 Price Change Tracking

Products are categorized based on whether their prices have increased, decreased, or remained unchanged compared to previous prices.

### 3. 🏪 Market-wise Price Information

View minimum and maximum prices from different markets to understand the price range of a product.

### 4. 🔐 User Authentication

Users can create an account, sign in, manage their profile, and securely sign out of the application.

### 5. 📱 Responsive & User-friendly UI

The application is designed to work smoothly across desktop, tablet, and mobile devices with a clean Bangla-first interface.

---

## 🛠️ Technologies Used

* **Next.js 16** – React framework for the application
* **React** – Building interactive user interfaces
* **TypeScript** – Type-safe development
* **Tailwind CSS** – Styling and responsive layouts
* **Better Auth** – User authentication
* **Sonner** – Toast notifications
* **DaisyUI** – Modern Components
* **Next.js App Router** – Application routing and server-side features
* **Vercel** – Deployment

## 📌 Project Highlights

BazarDor focuses on making market price information easy to understand for Bangla-speaking users.

The application includes:

* Product categories
* Current product prices
* Previous price comparison
* Percentage price changes
* Minimum and maximum market prices
* Product details pages
* User authentication
* Responsive navigation
* Bangla date and number formatting
